# Nav Coaching — المساعد العلمي الشخصي

تطبيق محلي يبني قاعدة معرفة من ملفاتك العلمية، ويجيب عن أسئلتك **من ملفاتك فقط** مع استشهاد دقيق (الملف، صفحة PDF، الصفحة المطبوعة، القسم، والنص الحرفي)، ويحلل ملفات المتدربين ويقترح برامج مرتبطة بالأدلة.

> أداة دعم لقرارك المهني، وليست بديلًا عن التقييم الطبي أو المهني.

---

## التشغيل

المتطلبات: Python 3.10 أو أحدث.

```bash
# Linux / macOS
./run.sh
# Windows
run.bat
```

ثم افتح: <http://127.0.0.1:8000>

التشغيل اليدوي:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # اختياري
python -m navcoach.main
```

الاختبارات:

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## التشغيل التلقائي على ويندوز والوصول من الآيباد

1. **التشغيل التلقائي:** انقري مرتين على `install-autostart.bat`.
   - ينشئ البيئة ويثبّت المتطلبات، ثم يسجّل التطبيق ليعمل في الخلفية دون نافذة عند كل تسجيل دخول لويندوز، ويتحقق أنه يعمل.
   - يمكن تشغيله مجددًا بعد تحديث الكود.
   - يستخدم «جدولة المهام» (Task Scheduler)، وإن لم تتوفر الصلاحية يستخدم مجلد بدء التشغيل.
2. **السجل:** `data\navcoach.log` (لا يحتوي نصوص ملفاتك).
3. **الإلغاء:** `uninstall-autostart.bat`. يوقف التطبيق ويلغي التشغيل التلقائي دون المساس ببياناتك.
4. **الآيباد عبر Tailscale:**
   - ثبّتي Tailscale على الكمبيوتر والآيباد بنفس الحساب.
   - فعّلي MagicDNS وHTTPS Certificates من لوحة تحكم Tailscale.
   - نفّذي مرة واحدة في موجه الأوامر: `tailscale serve --bg 8000`، ثم افتحي الرابط `https://<اسم-الجهاز>.<...>.ts.net` من Safari.
   - يبقى التطبيق على `127.0.0.1`، ولا يصل إليه إلا أجهزتك المسجلة في Tailscale.
5. **منع النوم:** الإعدادات ← الطاقة ← السكون: «أبدًا» أثناء التوصيل بالكهرباء.

## 📚 تلخيص الملفات والسلايدات (Summaries & Slides)

**المسار:** رفع الملف ← المعالجة ← القراءة والفهرسة ← الملخص ← أهم الموضوعات ← أهم النتائج ← السلايدات ← ملاحظات المتحدث ← وضع الدراسة ← الأسئلة ← اسأل الملف.

- **البدء:** من صفحة أي ملف في المكتبة: اختاري المستوى ثم **إنشاء الملخص**، أو من قسم **تلخيص الملفات** في القائمة الجانبية.
- **الملخص:** يضم الأقسام التالية:
  - نظرة عامة، وملخص سريع (الموضوع، الهدف، أهم نتيجة، لماذا هو مهم).
  - أهم النقاط **مرتبة حسب الأهمية**، والمفاهيم كما يعرّفها الملف، وأهم النتائج والأرقام.
  - المنهجية: نوع الدراسة، والعينة وخصائصها، والمدة، والتدخل، والمتغيرات، وطريقة القياس.
  - القيود، والخلاصة، والتطبيقات العملية، والجداول، والعلاقات بين المفاهيم، وملخص لكل قسم من أقسام الملف.
  - بجانب كل معلومة **المصدر ← الصفحة**: يفتح الملف على الصفحة أو يعرض المقطع الأصلي.
  - فهرس جانبي بعناوين الملف الرئيسية والفرعية، مع رابط **عرض المصدر**.
- **مستويات التلخيص:** سريع، قياسي، مفصّل، خبير. المستوى يغيّر مقدار التفاصيل فقط ولا يغيّر المصادر.
- **اشرح هذا:** متاح في كل قسم وكل سلايد، ويعرض: ماذا يعني؟ لماذا هو مهم؟ ماذا وجدت الدراسة؟ النقطة الأساسية. كل جزء من جمل الملف نفسه، وما لا يوجد يُعلَن أنه غير موجود.
- **السلايدات:**
  - **الترتيب التعليمي:** عنوان، ثم الصورة الكبيرة، ثم المفاهيم، والخلفية، والمنهجية (مخطط انسيابي)، والنتائج (أرقام بارزة)، والبيانات (رسم بياني من جدول الملف فقط)، وخريطة المفاهيم، والقيود، والتطبيقات، والخلاصة، وأهم ما يجب تذكره.
  - **ملاحظات المتحدث:** لكل سلايد ملاحظات أوسع، مع المصدر بجانب كل معلومة.
  - **المشغّل:** ملء الشاشة، والأسهم، ولوحة المفاتيح، والصور المصغّرة، وشريط التقدم، والبحث، وتكبير الخط، والوضع الداكن والفاتح، ومحادثة حول السلايد الحالي.
  - **التصدير:** إلى **PowerPoint** مع الملاحظات والرسوم البيانية، وإلى **PDF** عبر الطباعة.
- **وضع الدراسة:** بطاقات مفاهيم، وأهم النتائج، و«ماذا أتذكر؟»، والمفاهيم الخاطئة الشائعة إن ذكرها الملف. الأسئلة من نوع اختيار من متعدد، وصح/خطأ، وإجابة قصيرة، مع التصحيح والإجابة الصحيحة والشرح والمصدر.
- **اسأل هذا الملف:** يبحث في الملف المحدد فقط، ويقول «لم أجد هذه المعلومة في الملفات المتاحة لدي» إن لم يجدها.
- **الحفظ:** في قاعدة البيانات. يمكن إعادة الفتح، وتغيير الاسم، وإعادة التوليد بمستوى آخر، والحذف. إذا تغيّر الملف الأصلي يظهر تنبيه بأن الملخص مبني على نسخة سابقة. حذف الملف يحذف ملخصاته.

**ضمان الاعتماد على الملف فقط:**
- **بدون نموذج لغوي:** كل عبارة جملة حرفية من الملف، ويُعاد التحقق من وجودها في مقطعها.
- **مع نموذج لغوي:** تلخيص هرمي قسمًا قسمًا، فلا يُرسل الملف كاملًا دفعة واحدة. ثم يُدمج الناتج، وكل عبارة يجب أن تحمل اقتباسًا حرفيًا موجودًا فعلًا في المقطع المذكور. تُحذف العبارة إذا احتوت رقمًا غير موجود في الدليل، أو صياغة سببية والدليل ارتباطي، أو مقطعًا غير موجود. عدد العبارات المحذوفة وأسبابها يظهر في صفحة الملخص.
- **الرسوم:** الرسوم البيانية لا تُنشأ إلا من جداول الملف، وخريطة المفاهيم لا تُنشأ إلا من جمل تربط بين مفهومين.

**قيود معروفة:**
- **بدون نموذج لغوي:** «اشرح بطريقة أبسط» يعرض جمل الملف مرتبة تعليميًا ولا يعيد صياغتها.
- **التصنيف:** تصنيف الجمل (هدف، نتيجة، قيود...) وأسئلة الاختبار يعتمدان على أنماط لغوية إنجليزية أساسًا.
- **التصحيح:** تصحيح الإجابة القصيرة تقريبي (مطابقة أرقام أو كلمات). وعند الإجابة بالعربية على ملف إنجليزي يُطلب منك مقارنة إجابتك بإجابة الملف.

## إضافة ملفات علمية

1. صفحة **المكتبة العلمية** ← اسحب الملفات أو «اختر ملفات» أو «اختر مجلدًا»، أو الصق مسار مجلد على جهازك ثم «استيراد».
2. الصيغ المدعومة: PDF، DOCX، PPTX، XLSX، CSV، TXT، MD.
3. كل ملف يمر بالحالات: «بانتظار المعالجة» ← «قيد المعالجة» ← «تمت المعالجة» / «يحتاج إلى مراجعة» / «فشلت المعالجة».
4. افتح الملف لترى **تقرير الاستخراج**: كل صفحة وهل قُرئت أم لا، وعدد الأحرف، والتحذيرات. الصفحة الممسوحة ضوئيًا دون OCR تظهر «لم تُقرأ» ولا تُستخدم.
5. الملف المكرر (نفس المحتوى) يُرفض. الملف بالاسم نفسه ومحتوى مختلف: يسألك (استبدال وإعادة المعالجة دون نسخة مكررة، أو الاحتفاظ بالاثنين).
6. إضافة ملف جديد لا تعيد معالجة الملفات السابقة.
7. صحّح العنوان/المؤلف/السنة، وأضف الوسوم والمجموعات (التضخم، القوة، التغذية، التأهيل، النوم...) من صفحة الملف.

## طرح الأسئلة

صفحة **اسأل مكتبتي**: اكتب سؤالك بالعربية أو الإنجليزية. ستحصل على:
- عبارات كل منها مرتبط بدليل (`E1`, `E2`...) — انقر لفتح الدليل أو فتح الملف على الصفحة نفسها.
- قسم **تعارض بين المصادر** عند اختلاف النتائج، مع عرض الطرفين.
- القيود والفجوات، والعبارات التي حذفها المدقق.
- إذا لم توجد أدلة: «لم أجد في الملفات التي زودتني بها أدلة كافية للإجابة عن هذا السؤال».

تبويب **مقارنة الدراسات**: جدول (التصميم، العينة، المدة، المتغيرات، النتائج، القيود، الصلة بسؤالك). كل خانة اقتباس حرفي أو «غير مذكور في الملف».

## تحليل ملف متدرب

1. **تحليل المتدربين** ← متدرب جديد.
2. أدخل البيانات يدويًا و/أو ارفع ملفه (TXT/DOCX/PDF/XLSX/CSV). الصيغة الأفضل سطور مثل `Goal: hypertrophy` أو `الهدف: تضخم`، وسجل التمارين مثل `Squat: 3 sets x 6 reps @ 100 kg RPE 8`.
3. «تحليل» يعرض: الحقائق ومصدر كل منها (يدوي أو الملف + رقم السطر)، المعلومات الناقصة والأسئلة اللازمة، المؤشرات التي تستدعي تقييمًا مختصًا مع الإحالة المقترحة، والأولويات (موسومة «استنتاج») مع أدلتها من المكتبة.
4. «اقتراح برنامج»: يُرفض إن كانت البيانات الأساسية ناقصة (الهدف، الخبرة، الأيام، المعدات، الإصابات، الحالة الصحية) ويطرح الأسئلة. وعند وجود مؤشرات خطر لا يُقترح برنامج حتى تؤكد وجود تقييم/تصريح مختص.
5. البرنامج جدول عناصر (الأيام، التقسيم، التمارين، الحجم، التكرارات، RIR/RPE، الراحة، التدرج، المتابعة). لكل عنصر: قيد المتدرب، القيم المذكورة حرفيًا في المصادر مع المرجع، القيمة المقترحة، الأساس (دليل / قرار المدرب / لا يوجد دليل)، وحدود التطبيق (مثل: «الدليل من مدرَّبين بينما المتدرب مبتدئ»).
6. «تعديل البرنامج» ينشئ نسخة جديدة ويشترط سبب التعديل؛ النسخ السابقة محفوظة مع الفروقات. التصدير: Markdown أو CSV أو نسخ.

## كيف تُضمن الإجابات المقيدة بملفاتك

| الطبقة | ماذا تفعل |
|---|---|
| حارس الشبكة (`netguard.py`) | خطاف تدقيق في Python يمنع أي اتصال غير محلي (DNS أو socket). لا يُسمح إلا لمزود النموذج الذي اخترته ووافقت عليه. كل محاولة تُسجَّل وتظهر مع كل إجابة. |
| الاسترجاع الهجين (`index.py`) | BM25 عبر SQLite FTS5 + متجهات، ودمج النتائج. ترجمة مصطلحات عربية←إنجليزية للبحث فقط. |
| بوابة الصلة | المقطع يجب أن يغطي ≥50% من مفاهيم السؤال (قابل للتعديل). إن لم يجتزها أي مقطع ← رفض الإجابة **دون استدعاء النموذج**. |
| التوليد | بلا نموذج: اقتباسات حرفية فقط. مع نموذج: يُطلب JSON بعبارات مع رقم المقطع واقتباس حرفي، ونصوص الملفات تُقدَّم كبيانات غير موثوقة. |
| المدقق (`verify.py`) | يرفض العبارة إذا: استشهدت بمقطع لم يُسترجع، أو الاقتباس غير موجود حرفيًا في المقطع، أو فيها رقم غير موجود في الدليل، أو صياغة سببية والدليل ارتباطي، أو مفرداتها لا تطابق الدليل، أو الاقتباس نص يشبه التعليمات، أو حكم عليها فحص ثانٍ بأنها غير مدعومة. |
| التعارض | كشف آلي لاتجاهات متعاكسة (زيادة/لا فرق/انخفاض) بين ملفات مختلفة على كل المقاطع ذات الصلة، لا على المختار فقط. |
| حقن التعليمات | المقاطع التي تحوي «تجاهل التعليمات...» تُوسَم، وتُستبعد من الاقتباسات، والملف يُعلَّم «يحتاج إلى مراجعة». |

لا يدّعي النظام أنه «تعلّم» ملفاتك؛ كل إجابة تعتمد على استرجاع فعلي من قاعدة المعرفة المحفوظة لحظة السؤال.

## مزود النموذج (قابل للتبديل)

من **الإعدادات**:
- **بدون نموذج** (الافتراضي): أعلى أمان؛ الإجابة اقتباسات حرفية مع استشهادات، دون صياغة أو تركيب.
- **Ollama** (محلي، موصى به): ثبّت Ollama ثم مثلًا `ollama pull qwen2.5:7b-instruct`.
- **خادم متوافق مع OpenAI** (LM Studio / llama.cpp) محلي.
- **Claude API** (خارجي): ضع `ANTHROPIC_API_KEY` في `.env` و`pip install anthropic`، ثم وافق صراحة في الإعدادات. يُرسَل فقط المقاطع المسترجعة، لا الملفات كاملة. بيانات المتدربين تحتاج موافقة منفصلة.

البحث الدلالي: الافتراضي مدمج ويعمل دون إنترنت لكنه **تشابه لفظي** لا دلالي حقيقي. للبحث الدلالي الأقوى (وخاصة أسئلة عربية على مراجع إنجليزية): اختر Ollama مع `ollama pull bge-m3` ثم «إعادة بناء الفهرس».

## التخزين والنسخ الاحتياطي

- كل البيانات في `data/` (أو `NAV_DATA_DIR`): `navcoach.db` (SQLite: الملفات، المقاطع، الفهرس، المتجهات، السجل، المتدربون، البرامج)، `library/<id>/` نسخ الملفات الأصلية، `clients/<id>/` ملفات كل متدرب منفصلة، `backups/`.
- **الإعدادات ← النسخ الاحتياطي**: ملف ZIP (قاعدة البيانات + الملفات الأصلية + الإعدادات، دون `.env`). الاستعادة تحفظ نسخة أمان من الوضع الحالي أولًا.
- **إعادة بناء الفهرس** يعيد الاستخراج من الملفات الأصلية (لازم بعد تغيير مزود التضمين).
- الحذف (ملف، متدرب، برنامج) نهائي ويطلب تأكيدًا، ويزيل المقاطع والفهارس والملفات المرتبطة.

## الخصوصية

- التخزين محلي افتراضيًا، والخادم يستمع على `127.0.0.1` فقط.
- لاستخدامه من جهاز لوحي على الشبكة المنزلية: `NAV_HOST=0.0.0.0` و`NAV_ACCESS_TOKEN=<قيمة طويلة>` ثم افتح `http://<ip>:8000/login?token=<القيمة>` مرة واحدة.
- المفاتيح تُقرأ من `.env` فقط؛ لا تُعرض في الواجهة ولا تُكتب في السجلات. السجلات لا تحتوي نصوص الملفات.

```
navcoach/

  chunking.py   تقسيم لا يعبر حدود الصفحة (استشهاد دقيق)

  ingest.py     الرفع، إزالة التكرار، الاستبدال، الحذف، إعادة البناء، الطابور الخلفي
  llm.py        مزودو النموذج + فرض الموافقة على الخصوصية
  rag.py        السؤال ← استرجاع ← بوابة صلة ← توليد ← تحقق ← سجل
  verify.py     التحقق من العبارات وكشف التعارض
  compare.py    جدول مقارنة الدراسات
  clients.py    ملفات المتدربين، الحقائق، النواقص، المؤشرات الحمراء
  programs.py   البرامج المرتبطة بالأدلة والنسخ
  backup.py     النسخ الاحتياطي والاستعادة
  netguard.py   منع الاتصال الخارجي
  docmodel.py   بنية الملف الواحد (العناوين، الجمل، الجداول) من مقاطعه المخزنة
  summarize.py  التلخيص (حرفي أو هرمي بنموذج) + التحقق + الحفظ
  slides.py     السلايدات التعليمية + تصدير PowerPoint
  study.py      وضع الدراسة، الأسئلة، اشرح هذا، محادثة السلايدات، اسأل الملف
  main.py       FastAPI + الواجهة (static/)
tests/          اختبارات آلية (منها الاختبارات التسعة الإلزامية في test_required.py)
```

## القيود المعروفة

- **OCR**: الصفحات الممسوحة تُقرأ فقط إذا كان برنامج `tesseract` مثبتًا؛ وإلا تُعلَّم «لم تُقرأ» صراحة.
- **البحث الدلالي المدمج** لفظي؛ التشابه الدلالي الحقيقي يحتاج Ollama/fastembed.
- **وضع «بدون نموذج»** لا يركّب إجابة؛ يعرض عبارات حرفية من ملفاتك فقط.
- **كشف التعارض** قائم على أنماط لغوية إنجليزية (increase / no significant difference ...)؛ قد يفوته تعارض بصياغة غير مألوفة أو ينبّه على تعارض ظاهري — اقرأ الطرفين دائمًا.
- **التحقق من العبارات المترجمة** (عبارة عربية ودليل إنجليزي) يعتمد على فحص الأرقام والاقتباس الحرفي وفحص النموذج الثاني، لا على تطابق المفردات؛ لذلك يُعرض الاقتباس الأصلي بجانب كل عبارة.
- **استخراج القيم للبرنامج** (أيام، مجموعات، تكرارات، RIR، راحة) يعتمد على أنماط نصية إنجليزية؛ اختيار التمارين والتقسيم يُترك «قرار المدرب» ما لم يذكر المصدر قيمة.
- **الصفحة المطبوعة** تُكتشف من تسميات صفحات PDF أو أرقام الترويسة/التذييل عند اتساقها؛ وإلا تظهر «غير محددة».
- **بيانات الوصف** (العنوان، السنة، النوع) مكتشفة آليًا وقد تحتاج تصحيحًا يدويًا.

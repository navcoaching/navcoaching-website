# Nav Coaching — منصة البرامج والطلبات

موقع عربي (RTL) لعلامة Nav Coaching: عرض البرامج، الشراء بتقييم المتدرب، الدفع بالتحويل البنكي مع مراجعة المدربة، حساب للمتدرب يتابع فيه طلباته وملفاته ومراجعاته الأسبوعية وتقييمه، ولوحة إدارة محمية للمدربة.

> **الحالة:** نسخة جاهزة للتجربة على رابط Preview. **ليست جاهزة للبيع** قبل إكمال البنود في [docs/DELIVERY.md](docs/DELIVERY.md) (البريد، قاعدة البيانات، مراجعة المحتوى).

## التقنية ولماذا

| الجزء | الاختيار | السبب |
|---|---|---|
| الموقع والخادم | Next.js 16 (App Router) + TypeScript | صفحات عامة سريعة (ثابتة مع تحديث تلقائي)، ومنطق الخادم في نفس المشروع |
| قاعدة البيانات | PostgreSQL (أي مزود مُدار: Neon أو Supabase) | **الصلاحيات داخل قاعدة البيانات (RLS)**: حتى لو أخطأت الواجهة لا يرى عميل بيانات عميل آخر |
| الدخول | Better Auth برمز يصل للبريد (بدون كلمة مرور) | أبسط على الجوال، ولا كلمات مرور تتسرّب |
| البريد | Resend | إرسال رمز الدخول والتنبيهات |
| الملفات | Netlify Blobs (تخزين خاص) | الإيصالات والملفات لا تُفتح إلا بعد التحقق من الصلاحية |
| الاستضافة | Netlify (موقع جديد مستقل) | الموقع الحالي يبقى يعمل حتى نقل الدومين |

الموقع الحالي كان ثابتاً بالكامل (HTML + Netlify Forms)، ولا يدعم حسابات أو صلاحيات أو تتبع طلبات، لذلك بُني المشروع من جديد، ونُقل المحتوى والأسعار والنموذج كما هي.

## التشغيل على جهازك

المتطلبات: Node.js 22، وPostgreSQL 16.

```bash
npm install
cp .env.example .env.local          # عدّلي القيم
```

أنشئي الأدوار وقاعدة البيانات (مرة واحدة):

```sql
CREATE ROLE nav_owner LOGIN PASSWORD '...';
CREATE ROLE nav_app   LOGIN PASSWORD '...' NOSUPERUSER NOBYPASSRLS;
CREATE DATABASE nav_dev OWNER nav_owner;
```

```bash
npm run db:migrate     # إنشاء الجداول والصلاحيات
npm run db:seed        # استيراد المحتوى الحقيقي من الموقع الحالي
npm run dev            # http://localhost:3000
```

- في التطوير، إذا لم يوجد مفتاح Resend، تُحفظ رسائل رمز الدخول في جدول `dev_mailbox` (وتظهر في سجل الخادم). **هذا لا يعمل في الإنتاج إطلاقاً.**
- حساب المدربة: سجّلي الدخول مرة من `/login`، ثم: `npm run make-coach -- your@email.com`
- بيانات تجريبية للتطوير فقط: `npm run db:seed-demo`، وحذفها: `npm run db:purge-demo`

## الاختبارات

```bash
npm run typecheck
npm run test:db        # 18 اختبار صلاحيات على مستوى قاعدة البيانات (قاعدة nav_test منفصلة)
npm run test:e2e       # رحلة كاملة على iPhone وiPad وDesktop (قاعدة nav_e2e منفصلة)
```

الاختبارات تُنشئ قواعدها من الصفر، ولا تلمس قاعدة التطوير أو الإنتاج.

## النشر على Netlify (رابط Preview أولاً)

> **الدليل التفصيلي خطوة بخطوة (بدون أوامر على جهازك):** [docs/DEPLOY.md](docs/DEPLOY.md). قاعدة البيانات تُجهَّز بلصق [`db/setup.sql`](db/setup.sql) في محرر SQL.


1. **قاعدة البيانات:** أنشئي مشروع Postgres (Neon أو Supabase)، ثم نفّذي أوامر الأدوار أعلاه عليه.
2. من جهازك، بقيم الإنتاج في `.env.local` (أو متغيرات مؤقتة):
   `npm run db:migrate && npm run db:seed`
3. **Netlify:** أنشئي **موقعاً جديداً** من هذا المستودع (لا تستبدلي الموقع الحالي). الإعدادات في `netlify.toml`.
4. **متغيرات البيئة في Netlify** (Site settings → Environment variables):
   `DATABASE_URL` (بدور nav_app فقط)، `DATABASE_SSL=true`، `BETTER_AUTH_SECRET`، `BETTER_AUTH_URL`، `NEXT_PUBLIC_SITE_URL`، `RESEND_API_KEY`، `MAIL_FROM`، `COACH_NOTIFY_EMAIL`، `STORAGE_DRIVER=netlify`.
   **لا تضعي `DATABASE_URL_OWNER` في Netlify.**
5. جرّبي على رابط `*.netlify.app` رحلة كاملة بطلب حقيقي بمبلغ رمزي، ثم ألغيه.
6. بعد الموافقة: انقلي الدومين `navcoaching.sa` إلى الموقع الجديد (انظري خطة الترحيل).

## إدارة الموقع (للمدربة)

من `/admin`:

- **الطلبات:** تصفية حسب الحالة، بحث برقم الطلب أو الاسم أو الجوال أو البريد، فتح الإيصال، ثم **اعتماد الدفع بعد التأكد من وصول المبلغ في كشف الحساب** (خانة إلزامية)، أو رفض الإيصال مع سبب يظهر للعميل. كل تغيير يُسجّل باسمك ووقته، والسجل لا يُعدّل.
- **خصم الطالب:** يصل الطلب بحالة «بانتظار تأكيد المبلغ». حددي المبلغ النهائي، أو 0 إن كان مجانياً.
- **الملفات:** أضيفي رابطاً أو ملفاً حتى 5MB لكل طلب. يظهر للعميل فقط عندما يكون طلبه نشطاً أو مسلّماً.
- **المنتجات:** الأسعار والمدد والنصوص والنشر. تعديل السعر لا يغيّر الطلبات السابقة.
- **التقييمات:** اعتماد، أو رفض أو إخفاء مع سبب، أو رد علني. لا يمكن تعديل نص أي تقييم.
- **المحتوى:** رابط YouTube Shorts ونصه، ونصوص الواجهة، ومدة الرد، وواتساب، والحساب البنكي، ونبذتك، وأسئلة المراجعة الأسبوعية، والأسئلة الشائعة، والسياسات.
- **الصور:** ارفعي صورك المملوكة أو المرخّصة مع ذكر المصدر. لا تظهر أي صورة قبل «اعتماد النشر».

## الأمان باختصار

- الصلاحيات تُفرض في قاعدة البيانات (RLS)، وفي الخادم، ثم في الواجهة. التطبيق يتصل بدور لا يملك الجداول ولا يتجاوز RLS.
- الطلبات والإيصالات والتقييمات لا تُكتب مباشرة، بل عبر دوال تتحقق من الملكية والحالة. **السعر يُقرأ دائماً من قاعدة البيانات.**
- رفع الملفات: فحص النوع الفعلي للملف لا امتداده، وحد 5MB، وإعادة ترميز الصور (تزيل بيانات الموقع EXIF)، وخدمة الملفات مع `nosniff`. **لا يوجد فحص فيروسات.**
- حدود للطلبات على الدخول والطلبات والإيصالات والتقييمات، وحقل خفي ضد الرسائل الآلية.
- البيانات الصحية في عمود منفصل، ولا تُرسل في أي بريد أو تنبيه.
- ترويسات أمان وسياسة CSP. HTTPS وHSTS على Netlify.

## النسخ الاحتياطي

- فعّلي النسخ الاحتياطي التلقائي أو الاستعادة لنقطة زمنية لدى مزود قاعدة البيانات (تختلف حسب الخطة).
- نسخة يدوية دورية: `pg_dump "$DATABASE_URL_OWNER" -Fc -f nav-$(date +%F).dump`
- الاسترجاع: `pg_restore -d "<قاعدة جديدة>" nav-YYYY-MM-DD.dump`
- ملفات Netlify Blobs: لا تُنسخ تلقائياً مع قاعدة البيانات. راجعي [docs/DELIVERY.md](docs/DELIVERY.md).

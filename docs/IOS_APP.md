# تطبيق iOS — الخطة وأين وصلنا

المرجع الوحيد لمشروع التطبيق. كل جلسة عمل تبدأ بقراءته وتنتهي بتحديث قسم «الحالة».

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| التقنية | Expo (React Native) + TypeScript في مجلد `mobile/` | أداء أصلي للمتتبّع، بدون جهاز Mac (البناء والرفع من سحابة Expo)، وAndroid لاحقاً بنفس الكود |
| الخادم | نفس موقع Next.js، بواجهات جديدة تحت `/api/mobile/v1/*` | قاعدة واحدة وصلاحيات RLS نفسها؛ لا خادم ثانٍ |
| الدخول | نفس رمز البريد (better-auth + إضافة expo) | لا يشترط Sign in with Apple (البند 4.8) |
| المجاني | بناء جدول + تسجيل الأوزان + الرسوم؛ يعمل **بدون تسجيل** ويُحفظ على الجهاز | البند 5.1.1(v)، ويعمل في النادي بدون إنترنت |
| المدفوع | المتابعة مع المدربة؛ الدفع بالتحويل البنكي ورفع الإيصال | البند 3.1.3(d): التدريب الشخصي الفردي مستثنى من الشراء عبر Apple |
| الاسم ومعرّف التطبيق | Nav Coaching — `com.navcoaching.app` — الرابط `navcoaching://` | |
| حساب Apple | باسم المؤسسة (يتطلب D-U-N-S) | يظهر «Nav Coaching» كبائع |
| الأجهزة | iPhone فقط في الإصدار الأول | iPad يضاعف الصور المطلوبة والمراجعة |
| اللغة والاتجاه | عربي، RTL إجباري (`forcesRTL`) | |

## المراحل

- [x] **0 — الأساس:** هيكل التطبيق، الدخول برمز البريد، شاشة الحساب، واجهة `/api/mobile/v1/me`.
- [x] **1 — المتتبّع المجاني (الأساس):** بناء برنامج (أيام، تمارين من مكتبة المدربة 208 تمريناً، جولات، تكرارات، وزن مستهدف، راحة)، تمرين جارٍ مع «المرة السابقة»، أنواع الجولات (إحماء/دروب)، مؤقت راحة بتنبيه، إنهاء بملخص وأرقام قياسية، السجل، صفحة التمرين (فيديو، بدائل، سجلك). حفظ محلي (SQLite) بدون حساب.
- [x] **1ب — برامج ساره المجانية داخل التطبيق:** خيار «برنامج مجاني في تطبيق الجوال» في صفحة القالب بلوحة الإدارة؛ يظهر في التطبيق (الأسبوع الأول فقط) ويُنسخ للجوال بضغطة.
- [x] **2 — التقدم والتنبيهات:** رسوم 1RM التقديري وأثقل وزن لكل تمرين، أعمدة التمارين الأسبوعية، اقتراح وزن اليوم (تدرج مزدوج حسب مدى التكرارات)، بطاقة إنجاز للمشاركة، تذكير أيام التمرين (محلي). تبويب «حسابي» يعمل للزائر.
- [x] **3 — منطقة المتدرب:** برنامج المدربة (الأسابيع، الأيام، المستهدف، ملاحظات المدربة) وتسجيله بنفس قواعد الموقع؛ طلباتي مع بيانات التحويل ونسخ الآيبان ورفع الإيصال (ألبوم أو كاميرا) وإلغاء الطلب؛ برامج المتابعة تُفتح من الموقع داخل التطبيق؛ «خلّ الكوتش تراجع تقدمك» بعد 8 تمارين؛ **حذف الحساب من التطبيق**.
- [x] **مطابقة الموقع (دفعة 1):** أيقونة وشاشة بداية من الشعار؛ التغذية (أهداف اليوم، أكل اليوم مع التنقل بين الأيام، إضافة من الوجبات الجاهزة أو البحث بالغرام أو إدخال حر، الجداول الغذائية، المكملات)؛ التقدم (الوزن مع رسم، القياسات، الخطوات، الأرقام القياسية)؛ تقييم اليوم.
- [x] **خدمات الكوتش بأسعار رمزية:** «راجعي جدولي» (يرسل البرنامج وسجل 4 أسابيع)، «تصحيح أداء تمرين» (فيديو حتى 20 ثانية، تحت 5 ميجا)، «وجباتي» (وجبات قوالب التغذية). منتجات عادية في لوحة الإدارة بحقل «خدمة إضافية في تطبيق الجوال»، والطلب يظهر في صفحة الطلب للمدربة. ⚠️ «وجباتي» محتوى رقمي: بيعه داخل التطبيق يلزمه الشراء عبر Apple؛ حالياً يظهر للمشتركين فقط، وزر الشراء في التطبيق مؤجل لحين ربط مشتريات Apple.
- [x] **مطابقة الموقع (دفعة 2):** تفاصيل الطلب في التطبيق: ملفات البرنامج (تحميل محمي بالجلسة)، المراجعة الأسبوعية وردود المدربة (نص وفيديو)، وتقييم التجربة.
- [x] **مطابقة الموقع (دفعة 3):** بياناتي (الاسم) وتفضيلات التواصل، موعد البداية قبل التفعيل، التجديد بخصم 10% في آخر أيام الاشتراك، استبيان نهاية البرنامج، تبديل التمرين ببديل من قائمة المدربة.
- [x] **مطابقة الموقع (دفعة 4):** تبويب «اكتشف»: البرامج والباقات بأسعارها وتفاصيلها، الجداول المجانية (طلب وتحميل PDF) والكتيبات، حاسبة السعرات وتوازن الطاقة (نفس ملف الموقع `src/lib/calories.ts` منسوخ بسكربت `mobile/scripts/sync-shared.mjs` واختبار يمنع اختلافه)، عن المدربة، التقييمات، الأسئلة الشائعة، السياسات.
- [x] **تبديل التمرين بمشابه (المتتبّع المجاني):** زر ⇄ في البرنامج وفي التمرين الجاري (`mobile/src/lib/similar.ts`). للجميع: بدائل عامة من نفس العضلة/الأداة. في التمرين الجاري: قبل إكمال أي جولة فقط، ومع خيار «بدّله في البرنامج».
- [x] **الدفع الخارجي داخل التطبيق (مراجعة Apple):** الباقات تدريب شخصي (3.1.3(d))، و«راجعي جدولي» و«تصحيح الأداء» يُرد عليها على واتساب، أي خدمة تُستهلك خارج التطبيق (3.1.3(e)). لا روابط شراء للموقع داخل التطبيق: «شوف البرامج» تفتح الباقات في التطبيق. خطة احتياطية: مفتاح «الطلب من تطبيق الجوال» في لوحة الإدارة (المحتوى والإعدادات): متوقف = الباقات تعريفية بدون أسعار، والخدمات الإضافية مخفية، والخادم يرفض الطلب من التطبيق؛ الموقع لا يتأثر. يبقى شغالاً وقت المراجعة، ولا يُشغَّل بعد القبول إن كان متوقفاً وقتها (2.3.1(a)).
- [x] **«ناف برو» — بدائل الكوتش ساره (مدفوعة):** البدائل اللي تحددها المدربة لكل تمرين من لوحة الإدارة (`exercise_alternatives`) تظهر أولاً بترتيبها في شاشة التبديل وصفحة التمرين، للمشترك فقط. لم تعد مضمّنة في التطبيق؛ تُجلب من `/api/mobile/v1/coach-alts` وتُحفظ على الجهاز للنادي بدون إنترنت. الاستحقاق في قاعدة البيانات `app.has_pro()`: المدربة أو اشتراك متابعة جارٍ (ضمن الباقة)، واشتراك Apple يُضاف لها لاحقاً. شاشة `/pro` بدون أي سعر أو رابط دفع خارجي.
- [ ] **اشتراك «ناف برو» عبر Apple (بعد توفر الحساب):** اشتراك متجدد تلقائياً (3.1.2) يجمع بدائل الكوتش + «وجباتي» (قرار المالكة). «وجباتي» لم تعد تُباع بالتحويل في التطبيق؛ الاستحقاق `app.has_meals()` = عنده برنامج أو اشتراها من الموقع أو «ناف برو». يلزم: منتجات الاشتراك في App Store Connect، مكتبة StoreKit في التطبيق، التحقق من المعاملات في الخادم (مكتبة Apple الرسمية `@apple/app-store-server-library` + إشعارات App Store Server)، زر «استعادة المشتريات»، وروابط الشروط والخصوصية في شاشة الاشتراك. TestFlight يختبر الشراء ببيئة Sandbox بدون خصم فعلي.
- [x] **مطابقة الموقع (الدفعة 5، الأخيرة):** طلب الباقة بالاستبيان كاملاً من داخل التطبيق: 5 خطوات بنفس أسئلة الموقع وخياراته ونصوص لوحة الإدارة وأسئلتها الإضافية (`/api/mobile/v1/checkout`)، مسودة على الجهاز بدون البيانات الصحية، موعد البداية، والإرسال بعملية `create-order` (نفس تحقق الموقع: `src/lib/create-order.ts` يستخدمه الموقع والتطبيق)، ثم صفحة الطلب ببيانات التحويل. الدفع بتحويل بنكي: تدريب شخصي (3.1.3(d)).
- [ ] **مؤجل بعد البيتا:** مزامنة سجل المتتبّع مع الحساب، «صوّر جدولك»، RIR في المتتبّع المجاني.

## التشغيل والفحص

```bash
cd mobile
npm install
npm run typecheck                 # فحص الأنواع
npx expo-doctor                   # فحص الإعدادات والتوافق
npx expo export --platform ios    # يتأكد أن حزمة iOS تُبنى
EXPO_PUBLIC_API_URL=http://<ip>:3000 npx expo start   # تجربة على خادم محلي
```

```bash
npx eas-cli@latest build --platform ios --profile production

```

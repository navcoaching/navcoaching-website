# تطبيق iOS — الخطة وأين وصلنا

المرجع الوحيد لمشروع التطبيق. كل جلسة عمل تبدأ بقراءته وتنتهي بتحديث قسم «الحالة».

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| التقنية | Expo (React Native) + TypeScript في مجلد `mobile/` | أداء أصلي للمتتبّع، بدون جهاز Mac (البناء والرفع من سحابة Expo)، وAndroid لاحقاً بنفس الكود |
| الخادم | نفس موقع Next.js، بواجهات جديدة تحت `/api/mobile/v1/*` | قاعدة واحدة وصلاحيات RLS نفسها؛ لا خادم ثانٍ |
| الدخول | نفس رمز البريد (better-auth + إضافة expo) | لا يشترط Sign in with Apple (البند 4.8) |
| المجاني | بناء جدول + تسجيل الأوزان + الرسوم؛ يعمل **بدون تسجيل** ويُحفظ على الجهاز | البند 5.1.1(v)، ويعمل في النادي بدون إنترنت |
| المدفوع | المتابعة مع المدربة؛ الدفع بالتحويل البنكي ورفع الإيصال | البند 3.1.3(d): التدريب الشخصي الفردي مستثنى من الشراء عبر Apple |
| الاسم ومعرّف التطبيق | Nav Coaching — `com.navcoaching.app` — الرابط `navcoaching://` | |
| حساب Apple | باسم المؤسسة (يتطلب D-U-N-S) | يظهر «Nav Coaching» كبائع |
| الأجهزة | iPhone فقط في الإصدار الأول | iPad يضاعف الصور المطلوبة والمراجعة |
| اللغة والاتجاه | عربي، RTL إجباري (`forcesRTL`) | |

## المراحل

- [x] **0 — الأساس:** هيكل التطبيق، الدخول برمز البريد، شاشة الحساب، واجهة `/api/mobile/v1/me`.
- [x] **1 — المتتبّع المجاني (الأساس):** بناء برنامج (أيام، تمارين من مكتبة المدربة 208 تمريناً، جولات، تكرارات، وزن مستهدف، راحة)، تمرين جارٍ مع «المرة السابقة»، أنواع الجولات (إحماء/دروب)، مؤقت راحة بتنبيه، إنهاء بملخص وأرقام قياسية، السجل، صفحة التمرين (فيديو، بدائل، سجلك). حفظ محلي (SQLite) بدون حساب.
- [x] **1ب — برامج ساره المجانية داخل التطبيق:** خيار «برنامج مجاني في تطبيق الجوال» في صفحة القالب بلوحة الإدارة؛ يظهر في التطبيق (الأسبوع الأول فقط) ويُنسخ للجوال بضغطة.
- [x] **2 — التقدم والتنبيهات:** رسوم 1RM التقديري وأثقل وزن لكل تمرين، أعمدة التمارين الأسبوعية، اقتراح وزن اليوم (تدرج مزدوج حسب مدى التكرارات)، بطاقة إنجاز للمشاركة، تذكير أيام التمرين (محلي). تبويب «حسابي» يعمل للزائر.
- [x] **3 — منطقة المتدرب:** برنامج المدربة (الأسابيع، الأيام، المستهدف، ملاحظات المدربة) وتسجيله بنفس قواعد الموقع؛ طلباتي مع بيانات التحويل ونسخ الآيبان ورفع الإيصال (ألبوم أو كاميرا) وإلغاء الطلب؛ برامج المتابعة تُفتح من الموقع داخل التطبيق؛ «خلّ الكوتش تراجع تقدمك» بعد 8 تمارين؛ **حذف الحساب من التطبيق**.
- [ ] **مؤجل بعد البيتا:** التغذية والمراجعة الأسبوعية داخل التطبيق (حالياً رابط للموقع)، مزامنة سجل المتتبّع مع الحساب، «صوّر جدولك»، RIR في المتتبّع المجاني.
- [ ] **1.1 قبل رمضان (~منتصف فبراير 2027):** وضع رمضان، فواصل القيمرز.
- [ ] **4 — بيتا TestFlight:** 20–50 متدرباً، مجاناً وبدون ربط بالدفع (البند 2.2).
- [ ] **5 — النشر:** صفحة المتجر، الصور، ملصق الخصوصية، ملاحظات المراجعة (تذكر 3.1.3(d) + حساب تجريبي)، الإرسال.

## مهام صاحب المشروع (لا يقدر Claude ينفذها)

1. [ ] طلب رقم **D-U-N-S** للمؤسسة (مجاني، 1–2 أسبوع): من صفحة التسجيل في Apple Developer.
2. [ ] التسجيل في **Apple Developer Program** باسم المؤسسة (99$ سنوياً): developer.apple.com/programs/enroll
3. [ ] حساب مجاني في **expo.dev**، ثم إنشاء Access Token وإضافته في إعدادات بيئة جلسة Claude باسم `EXPO_TOKEN` (لا يُلصق في المحادثة).
4. [ ] الموافقة على دمج تعديل الخادم في الموقع الحي (انظر «تعديلات على الموقع» أدناه).
5. [ ] التجربة على الجوال عند كل مرحلة وإرسال الصور والملاحظات.

## تعديلات على الموقع (الخادم)

كلها إضافات لا تغيّر سلوك الموقع:
- `src/lib/auth.ts`: إضافة `expo()` و`trustedOrigins: ["navcoaching://"]` حتى يقبل الخادم طلبات الدخول من التطبيق. الطلبات من أي مصدر آخر تُرفض (403).
- `src/app/api/mobile/v1/me/route.ts`: هوية المستخدم واشتراكه الحالي.
- `tsconfig.json`: استثناء `mobile/` من فحص أنواع الموقع.
- ترحيل `035_public_templates.sql` (عمودان في `program_templates` + دالة `app.public_programs()`)، وملفه لقاعدة الإنتاج: `db/updates/2026-10-08-public-templates.sql`.
- `src/app/api/mobile/v1/programs/route.ts`: برامج المدربة المنشورة (عامة، بدون دخول).
- صفحة القالب في لوحة الإدارة: خيار النشر في التطبيق + وصف قصير.
- ترحيل `036_self_delete.sql` (دالة `app.delete_my_account()`)، وملفه للإنتاج: `db/updates/2026-10-08-self-delete.sql`.
- واجهات: `coaching` (برنامج المتدرب)، `orders` (الطلبات وبيانات التحويل)، `actions/[name]` (قائمة مغلقة تستدعي عمليات الموقع نفسها: تسجيل تمرين، رفع إيصال، إلغاء طلب)، `account/delete`. و`/me` صار يقرأ الجلسة من قاعدة البيانات مباشرة.
- اختبار `tests/e2e/mobile-api.spec.ts` لكل واجهات التطبيق.

## التشغيل والفحص

```bash
cd mobile
npm install
npm run typecheck                 # فحص الأنواع
npx expo-doctor                   # فحص الإعدادات والتوافق
npx expo export --platform ios    # يتأكد أن حزمة iOS تُبنى
EXPO_PUBLIC_API_URL=http://<ip>:3000 npx expo start   # تجربة على خادم محلي
```

البناء والرفع (بعد جاهزية حساب Apple و`EXPO_TOKEN`):
```bash
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --latest
```

# تطبيق iOS — الخطة وأين وصلنا

المرجع الوحيد لمشروع التطبيق. كل جلسة عمل تبدأ بقراءته وتنتهي بتحديث قسم «الحالة».

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| التقنية | Expo (React Native) + TypeScript في مجلد `mobile/` | أداء أصلي للمتتبّع، بدون جهاز Mac (البناء والرفع من سحابة Expo)، وAndroid لاحقاً بنفس الكود |
| الخادم | نفس موقع Next.js، بواجهات جديدة تحت `/api/mobile/v1/*` | قاعدة واحدة وصلاحيات RLS نفسها؛ لا خادم ثانٍ |
| الدخول | نفس رمز البريد (better-auth + إضافة expo) | لا يشترط Sign in with Apple (البند 4.8) |
| المجاني | بناء جدول + تسجيل الأوزان + الرسوم؛ يعمل **بدون تسجيل** ويُحفظ على الجهاز | البند 5.1.1(v)، ويعمل في النادي بدون إنترنت |
| المدفوع | المتابعة مع المدربة؛ الدفع بالتحويل البنكي ورفع الإيصال | البند 3.1.3(d): التدريب الشخصي الفردي مستثنى من الشراء عبر Apple |
| الاسم ومعرّف التطبيق | Nav Coaching — `com.navcoaching.app` — الرابط `navcoaching://` | |
| حساب Apple | باسم المؤسسة (يتطلب D-U-N-S) | يظهر «Nav Coaching» كبائع |
| الأجهزة | iPhone فقط في الإصدار الأول | iPad يضاعف الصور المطلوبة والمراجعة |
| اللغة والاتجاه | عربي، RTL إجباري (`forcesRTL`) | |

## مهام صاحب المشروع (لا يقدر Claude ينفذها)

1. [ ] طلب رقم **D-U-N-S** للمؤسسة (مجاني، 1–2 أسبوع): من صفحة التسجيل في Apple Developer.
2. [ ] التسجيل في **Apple Developer Program** باسم المؤسسة (99$ سنوياً): developer.apple.com/programs/enroll
3. [ ] حساب مجاني في **expo.dev**، ثم إنشاء Access Token وإضافته في إعدادات بيئة جلسة Claude باسم `EXPO_TOKEN` (لا يُلصق في المحادثة).
4. [ ] الموافقة على دمج تعديل الخادم في الموقع الحي (انظر «تعديلات على الموقع» أدناه).
5. [ ] التجربة على الجوال عند كل مرحلة وإرسال الصور والملاحظات.

## تعديلات على الموقع (الخادم)

كلها إضافات لا تغيّر سلوك الموقع:
- `src/lib/auth.ts`: إضافة `expo()` و`trustedOrigins: ["navcoaching://"]` حتى يقبل الخادم طلبات الدخول من التطبيق. الطلبات من أي مصدر آخر تُرفض (403).
- `src/app/api/mobile/v1/me/route.ts`: هوية المستخدم واشتراكه الحالي.
- `tsconfig.json`: استثناء `mobile/` من فحص أنواع الموقع.

## التشغيل والفحص

```bash
cd mobile
npm install
npm run typecheck                 # فحص الأنواع
npx expo-doctor                   # فحص الإعدادات والتوافق
npx expo export --platform ios    # يتأكد أن حزمة iOS تُبنى
EXPO_PUBLIC_API_URL=http://<ip>:3000 npx expo start   # تجربة على خادم محلي
```

البناء والرفع (بعد جاهزية حساب Apple و`EXPO_TOKEN`):
```bash
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --latest
```
